# Reference-image architectural sketch prompt

Supply user-provided style image + verified original building photographs to an image tool capable of conditioning on references.

> Render a hand-drawn architectural panorama in a wide 16:9 black canvas. Keep the top ~55–65% empty for presentation headings. Place the verified actual landmarks at the bottom only, with a convincing visual center and respectful building proportions, using the reference photos for distinctive rooflines, arches, clock features and facades. Delicate gray pencil/chalk line art with mixed line weights, selectively detailed windows, foliage and soft horizontal contour waves. No hard-edged photo filters, no garish colors, no invented structural features, no unsupported official signage. Optional water reflection can be artistic but must be labeled illustrative. Preserve clear negative space and crisp lower-edge architecture.

If the user requests strict accuracy, work from photographs with manual vector tracing and human review; a prompt alone cannot guarantee it.
