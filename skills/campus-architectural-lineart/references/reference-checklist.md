# Reference verification checklist

- [ ] Confirm official building and campus name; record URL and source owner.
- [ ] Download an original photo or user-provided image, not a compressed search thumbnail.
- [ ] Note photo date, perspective, landmark shape, arches, signage, roofs and distinctive windows.
- [ ] Check redistribution terms and attribution/license restrictions.
- [ ] Clearly label collage/montage; do not suggest buildings that live on separate campuses stand side by side.
- [ ] Verify each rendered building against its photo. If exact accuracy matters, prefer approved manual drawing or tracing instead of unconstrained image synthesis.
- [ ] Verify inscriptions from authoritative school branding and add those as separate graphics; model-generated text can be wrong.

The Zhejiang University demo is **AI-generated illustrative art** whose landmarks have not been exhaustively geometry-verified. It is not an official school illustration.
