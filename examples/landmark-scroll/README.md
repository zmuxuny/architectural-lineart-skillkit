# Synthetic landmark-scroll planner fixture

This is **not** a real campus, not photo-grounded, not AI-generated architecture, and **not** a final commemorative illustration. It creates nine deliberately fabricated and labeled geometric line-art fixtures to demonstrate the architecture-first **composition planning**. There are no trees, lakes or landscape filler, only a minimal common architectural baseline.

```
python examples/landmark-scroll/create_synthetic_draft.py --out-dir dist/synthetic-landmark-scroll
```

Inspect `dist/synthetic-landmark-scroll/draft/draft-layout.png` and the `draft-guides.png`. These are draft guides, not printable merchandise. Actual architecture sourcing, real image-generation API calls, and `montage_audit.py` approval remain mandatory for real outputs.
