# 建筑地标画卷 · `landmark-scroll`（v0.5）

## 目标：建筑是绝对主体，画卷而不是风景或贴纸

用户要的校庆、城市/学校标志物展示，是 **6–10 个有来源的真实建筑地标构成的连续画卷**；不是“校门、钟楼、大楼三件素材放在一片树和水纹里”。这不是强行追求数字：事实证据不足时，应减少真实可用素材或明确报告阻塞，绝不能生成虚构建筑填满版面。

**建筑必须占主导**：以“有意义的视觉笔墨”计算，目标建筑 ≥85%，纯装饰景物 ≤5%。这两个值是指导 Agent 与视觉审查的**设计目标**，不是自动测量得到的准确像素比例。默认 **不要树、灌木、湖面、倒影、云纹、连续波浪线**。除非树木/水系本身就是用户指明且有依据的地标，否则不得用它们填补建筑间隙。真正的连接来自相邻建筑基底、轮廓节奏和统一的线描语言；可以有极轻的一根建筑基线。

## 与以前的模式有什么差别

| 用户意图 | 技术模式 | 建筑数与组合 |
| --- | --- | --- |
| 单栋实拍风格线稿 | `single-building` | 1；尽量忠于实拍 |
| 建筑素材目录 | `gallery-layout` | 多栋各自完整、彼此独立 |
| 校庆主画面（明确少量主角） | `commemorative-montage / hero-montage` | 2–5；主角突出，可适当辅助元素 |
| **学校/城市建筑标志物画卷** | **`commemorative-montage / landmark-scroll`** | **6–10；画面左中右均有地标，高低错落、统一线稿** |

当用户只说“为一个学校/城市设计校庆纪念画卷、帆布袋”等，**优先 `landmark-scroll`**，让 Agent 独立决定有辨识度、可核实的建筑候选与主次排序；不要反过来让用户设计 JSON 或选布局。

## 实现步骤

1. **建筑清单与事实证据**。6–10 栋地标，每栋独立核实建筑身份、照片、视角与关键轮廓，遵循 `reference_pipeline.py`；同一建筑的不同角度不是不同地标。地理上分离的建筑不能宣称真实共处一个拍摄机位。
2. **独立的真实图像参考输入**。Agent 用模型根据实拍参考画单建筑透明线稿，避免从名字推断具体建筑形态。每一栋保留可核验照片的来源和输出哈希。
3. **生成画卷构图**：

   ```bash
   python skills/campus-architectural-lineart/scripts/compose_v2.py plan \
     --manifest workspace/project.json --usage tote-bag \
     --archetype landmark-scroll --output workspace/artwork/montage-plan.json

   python skills/campus-architectural-lineart/scripts/compose_v2.py draft \
     --plan workspace/artwork/montage-plan.json \
     --output-dir workspace/artwork/montage-draft
   ```

   这一步输出的是**构图草图**，有明确的左右延展、高低节奏与很轻的建筑基线，不是最终作品，更不会用树木和水纹填空。
4. **整图统一重绘**。执行 `integrated_edit.py` 时，`landmark-scroll` 模式会把所有建筑的 PNG 和真实主视角照片整理成带建筑 ID 的多个 **2×2 参考图板**，并把画卷草图与风格图一同提交给图像生成 API。这样 8–10 栋建筑不会因为图片附件上限静默丢失部分地标。使用参考板是为了控制输入数量，**不等于原图质量完全保留**；后续审核仍按单栋原始实拍核对。
5. **成品审核而不是草图审核**。`montage_audit.py` 检查所有申报地标是否可识别、建筑是否占主导、有没有树水景压过主角，以及左中右是否组成连续建筑群。原有的结构真实性与哈希审查仍然有效。缺失地标、明显假结构或仍然像拼贴样张都不能自动通过。
6. **SVG 与调色 HTML**。只有最终生成作品审核通过，才可把最终 PNG 送入 `convert.py --approval` 和 `build.py`；不要把参考图板或草图拿来矢量化后当成完整成品。

## 视觉验收（人工与 Agent 都应看最终 PNG）

- **数量**：所选择的每栋真实建筑都能被认出；不是三组大建筑加大片风景。
- **横向分布**：建筑群跨越整个画面左、中、右，不是只挤在中心或两端。
- **高低韵律**：屋顶、门楼、现代楼立面、钟楼之间有层次，不能等尺寸平铺贴纸。
- **主体明显**：几乎不需要树木、湖面、水纹或云朵帮助形成画面完整感。
- **事实**：不改变屋顶形制、入口数量或塔楼轮廓，未知的细节不补造。
- **交付**：经过真正的全局统一重绘，形成高质量建筑画卷，而不是合成草稿。

## 重要边界

当前 v0.5 的构图规划、参考图板和审核门禁有离线模拟测试，但**没有经过真实建筑图片生成模型的质量与事实性基准测试**。真实图像模型可能仍会改错门窗或丢掉地标，应通过独立的 Codex 黑盒测试验证，不能只引用 CI 通过证明审美质量。
